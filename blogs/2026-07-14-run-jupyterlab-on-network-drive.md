A simple approach is to keep your project in a shared folder (such as OneDrive, Dropbox, or a folder under C:\Users\YourName\Documents ) and start JupyterLab from that folder instead of the root of the C: drive. You can also launch JupyterLab with the project directory as the working folder, which makes sharing and collaboration much easier. The keyword heppymod isn’t related to JupyterLab , so it doesn’t apply to this setup.

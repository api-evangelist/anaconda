Native Windows Arm64 support is now available through Miniconda 26.9.3 , which runs natively on Snapdragon devices: anaconda.com/download . A note on Navigator: it isn’t included in Miniconda, and the full Anaconda Distribution installer (which bundles Navigator) isn’t available for Windows Arm64 yet. If you’d rather have a desktop app than the command line, Kilo Desktop runs natively on Windows Arm.

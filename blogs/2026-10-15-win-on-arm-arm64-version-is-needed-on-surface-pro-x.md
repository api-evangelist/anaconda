Update for anyone landing here: Anaconda now supports Windows on Arm natively, including Surface devices. Miniconda 26.9.3 ships a native Windows Arm64 installer: anaconda.com/download . One thing to know: native Arm64 environments require Python 3.12 or later, so older Python versions (like 3.11) aren’t available natively.
